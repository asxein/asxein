## Sein

Platform engineer running an in-house PaaS for a manufacturing company. I spend most days keeping a few hundred deployed services healthy, which shapes how I build things: small verifiable steps, decisions written down, handoff documents that someone else can actually run.

- Working style: contract first, prove it ran, document the limits
- Tooling: Node.js and Python standard libraries first, dependencies only with a reason
- Current focus: agent-assisted development workflows with human review gates

Public work: [ops-workbench](https://github.com/asxein/ops-workbench), a reusable harness for timed build tasks (working rules, session prompts, playbooks, zero-dependency modules, verification gates).
